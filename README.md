# 💰 Expense Tracker

A simple and user-friendly web application for managing personal income and expenses.

## 📌 About the Project

Expense Tracker helps users keep track of their daily income and expenses in one place.

Users can add transactions, view their transaction history, monitor their balance, and understand their spending through visual reports and charts.

## ✨ Features

- 🔐 User Registration and Login
- 💰 Add Income
- 💸 Add Expenses
- 📋 Income History
- 📋 Expense History
- ✏️ Edit Income and Expenses
- 🗑️ Delete Income and Expenses
- 📊 Financial Reports
- 📈 Expense Charts
- 💵 Total Income
- 💸 Total Expense
- ⚖️ Balance Calculation
- 🐷 Savings Tracking
- 👤 User Profile
- 🔑 Change Password
- 🚪 Secure Logout
- 📱 Responsive User Interface
- 🟢 Modern Glassmorphism UI

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Chart.js
- Font Awesome
- Poppins Font
